PDF 转换工具

选择 PDF 文件，一键转为 Word 或 Excel。全程在浏览器本地处理，文件不会上传任何服务器。

📖 使用步骤

  1. 拖入或点击选择要转换的 PDF 文件
  2. 选择转换目标：Word·保真版 / Word·文字版 / Excel 表格
  3. 点击「开始转换」，等待处理完成
  4. 点击下载生成的文件
📄
点击选择，或将 PDF 文件拖到这里
仅支持 .pdf 格式，文件大小建议 ≤ 30MB
🖼️转 Word·保真
📝转 Word·文字
📊转 Excel
保真版会将每一页按原排版完整渲染成图片再嵌入 Word，因此 PDF 里的图片位置、素材、配色、表格、图表都会与原文 1:1 一致。文件体积会随页数增加而变大（页数多时建议选「标准」清晰度）。
⬇ 下载转换结果
三种模式说明：
• Word·保真版：版式 1:1 还原，最适合含图片、图表、复杂排版的 PDF，但文字默认以图片形式存在（可在选项中开启「可编辑文字层」）。
• Word·文字版：提取文字并按段落/标题还原，文字可直接编辑，但会丢失原始排版与图片，适合纯文字文档。
• Excel 表格：按坐标重建二维表格，适合表格型 PDF。
扫描件（纯图片 PDF）请使用「保真版」。转换结果仅供编辑参考，重要文档请核对后再使用。
